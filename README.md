# Grama-Kalyana Sports 🏆

A real-time digital scoreboard and local tournament management Android application developed using Generative AI concepts and Android technologies.

## 📱 Project Overview

Grama-Kalyana Sports is a mobile application designed to modernize village-level sports tournaments by replacing traditional paper-based score tracking with a real-time digital platform.

The app allows organizers to:
- Manage tournaments
- Update live scores
- Track player statistics
- Share match results
- Maintain historical sports records

Fans and viewers can follow matches live directly from their mobile devices.

# 🚀 Features

## 🏟 Tournament Management
- Create and manage tournaments

## 📡 Live Score System
- Real-time score updates
- Low-latency live synchronization

## 👤 Player Statistics
- Player performance tracking
